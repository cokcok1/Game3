# 九龍街頭 V0.81 — 真實比例與鏡頭修正版

此版本延續 V0.8 旺角 OSM 道路及建築輪廓，修正主角與車輛採用固定像素大小造成的比例錯誤。

- 人物高度參考 1.7 米、私家車長度 4.5 米、巴士約 11 米；道路及建築輪廓沿用 OSM 地圖米制座標。
- 建築物高度仍為**示意生成**（約 14–39 米），並非 OSM 實測樓高。
- 預設鏡頭放大至 3.2 倍，支援 1.4–6 倍縮放。
- 縮小人物及汽車碰撞判定、上車及出拳距離。
- 手機保留虛擬搖桿、縮放與動作按鈕。

部署：將本資料夾內全部檔案上傳 GitHub Pages Repository 根目錄。必須包括 mongkok-map.json。

注意：目前未經手機實機測試；極小人物在低縮放倍率可能較難辨認。
