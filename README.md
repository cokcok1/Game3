# 九龍街頭 V0.7 — 碰撞及徒手互動原型

## 功能
- 保留 V0.6 2.5D 斜角鏡頭、透明建築、手機圓形搖桿及速遞任務。
- 人物無法直接穿過行駛或停泊的交通車輛；NPC 亦會嘗試避車。
- 玩家須靠近車輛才能上車，避免遠距離憑空切換。
- 徒手出拳：電腦按 J，手機按「出拳 👊」；路人有簡單受擊、逃跑及通緝反應。
- 簡易同車道車距判斷，減少交通車輛重疊。

## 已知限制
- 街網仍然係示意街網，未匯入真實九龍 OSM 座標。
- 交通 AI、碰撞及 NPC 行為係初步實作，未有完整物理引擎、警察追捕或精細打鬥動畫。
- 上車後會將選中的交通車輛標記為已佔用；本版未提供完善的車輛歸還／停泊邏輯。
- 只作程式靜態檢查，未經手機實機測試。
