# 九龍街頭 V1.0 — 3D 旺角開放世界整合版

## 部署
將 ZIP 中的 `index.html`、`mongkok-map.json`、`manifest.webmanifest` 一起上傳至 GitHub Pages Repository 根目錄。必須透過 HTTPS / HTTP 存取，直接雙擊 HTML 無法讀取地圖 JSON。

## 已實作（原型級）
- 旺角 OpenStreetMap 道路中心線、建築輪廓與附近街道名稱、小地圖、地標定位；建築高度及道路寬度屬估算。
- WebGL 第三身 3D、360° 鏡頭、雙指縮放、手機搖桿、日夜切換。
- 3D 香港的士、小巴、私家車簡化模型，上落車、駕駛、煞車；程序化交通與簡化路口燈號。
- 行人移動、建築/車輛基本碰撞、商店示範入口。
- 徒手出拳、NPC 受擊短暫倒地及逃離、通緝星級、簡化追捕警員、生命值、被捕扣款。
- 限時速遞任務（在小地圖顯示目的地）、獎勵、現金、商店治療、本機 localStorage 存檔/載入。

## 操作
手機：左搖桿移動/駕駛；右側按鈕出拳、任務、儲存、上落車、煞車、鏡頭等；右邊空白畫面單指轉鏡頭、雙指縮放。電腦：WASD 移動、E 上落車、J 出拳、M 開任務、P 存檔、空白鍵煞車，滑鼠拖動轉鏡頭，滾輪縮放。

## 仍未完成（切勿當成完整 GTA 遊戲）
- 只涵蓋旺角附近區域，並非整個油尖旺或全九龍。
- 商店室內是示範介面，入口/店名不代表實際商戶。
- 沒有完整任務劇情、武器、可購物的車庫、NPC 複雜反擊/巡邏、真實交通號誌/車道、專業動畫及音效。
- 路口、建築碰撞、交通 AI、追捕 AI、NPC 行為皆為輕量簡化實作；可能有穿模或卡住。
- 地圖需線上由同源 GitHub Pages 載入，無第三方 API Key 或 CDN 依賴。
- 已進行語法、封裝與靜態檢查；未在真實 iPhone / Android 上完成實機驗收。
