# 九龍街頭 V0.6 — 2.5D 手機操作版

純前端、免費、無 API Key。將本 ZIP 內全部檔案放入 GitHub Pages 儲存庫根目錄即可。

## V0.6 更新
- 圓形虛擬搖桿：Pointer Events、多點觸控、放開回中，並停用控制區長按選取。
- 建築智能半透明：靠近或遮住玩家的建築透明化。
- 車輛旋轉：根據 2.5D 投影後的行進方向對齊車身。
- 平滑追蹤鏡頭與速度前瞻；縮放 +/- 及滑鼠滾輪。
- 保留任務、NPC、車流、碰撞、本機存檔。

## 注意
此版仍然使用**示意街網**，不是經真實 OSM 校準的旺角地圖；汽車交通 AI 仍然較簡單。尚未進行實機瀏覽器測試。
